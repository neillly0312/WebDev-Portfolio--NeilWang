🌐 Accessibility

✅ This website adheres to WCAG Standards are committed to providing all users with an equal access experience

  • 🔹 clear HTML structure: Use the correct title hierarchy to facilitate navigation for screen readers.
  • 🔹 键盘可操作性：所有交互元素(链接、按钮)均可通过Tab键聚焦，并带有视觉焦点指示器(:focus-visible)。
  • 🔹 colour contrast: Make it easier for readers to read through different colors.
  • 🔹 text scaling: Supports text enlargement without disrupting the layout.
  • 🔹 alt text: All decorative and informative images provide meaningful alt attributes.
