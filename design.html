💭 Design Thinking Process

🔄 Five-stage Practice of Design thinking

🧡 1. Thinking —— I have found that navigation clarity and color contrast are the most urgent needs, after conducting research on different user groups, including visually impaired users, the elderly, and mobile users.
💡 2. Define —— I want to design a website that not only showcases personal style but also makes it easy for everyone to access and accommodates information acquisition
🚀 3. Ideat —— Use appropriate contrast colors to keep the interface simple
⚙️ 4. Framework —— A five-page structure was quickly built and navigation hover feedback was designed. Also using css to achieve several functions
🔄 Test —— Testing my website, adaptive on different devices
